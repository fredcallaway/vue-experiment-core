# Consent Form

When updating a project consent form, do not guess.

The correct default behavior is to leave the placeholder consent content unchanged unless a real consent form can be found easily from the current context. Good sources include an explicitly named neighboring project, a file path provided by the user, or an existing project document whose purpose is clear.

If no real consent form is easy to identify, keep the placeholder and ask the user for the correct source. Consent text is study-specific and should not be inferred from task wording, experiment names, institution defaults, or similar projects unless the user has made that source relationship clear.
